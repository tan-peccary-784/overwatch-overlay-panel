# Overwatch Overlay Panel — feature reference

Overwatch Overlay Panel uses a concise workspace for panel placement, display groups, and session notes. The feature map follows the same order as the project navigation.

| Section | Description |
|---|---|
| Panel placement | A dedicated section for panel placement and the configuration details associated with that area. |
| Display groups | Display or performance-related options, with space for configuration and comparison information. |
| Session notes | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
